0x01 Spring Boot 敏感接口

接口分类 接口路径 核心功能 备注（版本/授权/历史漏洞）
Actuator 极高危 /actuator/heapdump 下载Java堆内存转储文件 含明文密码/密钥/Session；未鉴权时下载后用 Memory Analyzer / JDumpSpider 提取/etc/passwd、application.yml
Actuator 极高危 /actuator/env 展示应用全量环境变量与配置参数 含DB密码、AK/SK、Redis密码；联动 Spring Cloud Config POST /refresh+/env可触发JNDI RCE（Eureka + Spring Cloud < 2020）
Actuator 极高危 /actuator/configprops 展示所有Spring配置属性 含spring.datasource、spring.redis等连接凭证
Actuator 极高危 /actuator/beans 展示全量Spring Bean实例与依赖关系 辅助定位MessageBroker、Environment等危险Bean，结合/env实现RCE
Actuator 极高危 /actuator/dump 生成Java线程全量转储记录 泄露线程栈、内存地址、请求上下文，辅助反序列化链构造（与/threaddump内容类似）
Actuator 高危 /actuator/mappings 展示应用所有URL接口映射关系 未授权遍历全站接口，扩大攻击面
Actuator 高危 /actuator/httpexchanges 展示最近HTTP请求全量记录 含参数、Header、Cookie、Token（2.0+替换/trace）
Actuator 高危 /actuator/trace 展示HTTP请求追踪记录 Spring Boot 1.x核心端点，2.x默认移除
Actuator 高危 /actuator/loggers 动态管理应用日志配置与输出级别 可远程调整日志级别，辅助日志投毒/信息泄露
Actuator 高危 /actuator/jolokia JMX远程监控与操作接口 需引入jolokia-core依赖；通过JMX MBean（如javax.management.MBeanServerInvocationHandler链）实现RCE
Actuator 高危 /actuator/shutdown 远程优雅关闭Spring Boot应用 默认endpoints.enabled=false（禁用）；显式开启后可DoS
Actuator 中危 /actuator/info 展示应用版本、构建、环境信息 泄露Git提交、构建时间，辅助版本匹配漏洞
Actuator 中危 /actuator/health 展示应用与依赖组件的健康状态 含DB/Redis/磁盘连接状态；show-details: always时泄露详情
Actuator 中危 /actuator/metrics 展示系统性能、业务指标数据 辅助判断业务规模与高价值接口
Actuator 中危 /actuator/conditions 展示Spring自动配置条件评估结果 辅助梳理依赖与未启用功能
Actuator 中危 /actuator/scheduledtasks 展示应用所有定时任务配置与执行规则 辅助定位定时任务接口
Actuator 低危 /actuator/auditevents 展示应用审计事件记录 需开启审计功能，含用户操作轨迹
Actuator 低危 /actuator/caches 管理应用缓存实例与缓存数据 可清空缓存造成业务异常
Actuator 低危 /actuator/flyway 展示数据库Flyway迁移执行记录 泄露数据库脚本与表结构
Actuator 低危 /actuator/liquibase 展示Liquibase数据库变更执行记录 同上，泄露DB变更历史
Actuator 低危 /actuator/threaddump 生成Java线程转储快照 线程栈信息，辅助反序列化链构造
Actuator 低危 /actuator/sessions 管理Spring Session用户会话 可强制注销会话/踢用户下线
认证类 极高危 /login、/api/auth/login 用户登录认证接口 默认账号admin/123456；无验证码支持暴力破解
认证类 极高危 /resetPassword、/api/user/reset 密码重置/找回接口 可越权重置任意用户密码；短信验证码可爆破
认证类 极高危 /admin/role、/api/permissions 角色与权限管理接口 越权分配管理员权限；常见未授权访问
认证类 高危 /user/profile、/api/user/info 用户个人信息查询接口 IDOR遍历用户信息（含手机/邮箱/身份证）
数据操作 极高危 /upload、/api/file/upload 文件上传接口 未校验后缀可上传Webshell（解析漏洞联动）
数据操作 极高危 /download、/api/file/download 文件下载/读取接口 路径遍历读取/etc/passwd、application.yml
数据操作 极高危 /api/data/query、/admin/backup 数据库查询/备份接口 未授权查询全库数据/下载备份SQL
数据操作 极高危 /api/system/exec、/admin/cmd 系统命令执行接口 未授权直接RCE（极高频漏洞点）
配置管理 极高危 /api/config、/admin/settings 系统全局配置管理接口 可篡改密钥、白名单，业务劫持
配置管理 高危 /api/cache/clear、/admin/cache 缓存管理与清空接口 清空缓存造成业务拒绝服务
配置管理 高危 /api/logs、/admin/log 系统日志查询与管理接口 未授权读取含Token/密码的日志
配置管理 高危 /debug、/api/test 开发调试/测试接口 生产环境常残留，含完整业务逻辑

路径差异：Spring Boot 1.x Actuator默认无前缀（/env、/heapdump）；2.x+统一为/actuator/*，部分子应用自定义前缀需通过/actuator或JS/HTML指纹识别。

历史漏洞重点：

  • CVE-2016-4977：Spring Security OAuth2 RCE（需/oauth/authorize + spring-security-oauth2）
  • CVE-2017-8046：Spring Data REST RCE（PATCH方法）
  • CVE-2018-1273：Spring Data Commons RCE（/users端点SpEL注入）
  • CVE-2022-22965（Spring4Shell）：spring-webmvc JDK9+ RCE，需Tomcat+参数绑定
  • CVE-2022-22963：Spring Cloud Function SpEL RCE（/functionRouter）

SQL注入-极高危 /system/role/export 角色导出 <=v3.2.0版本，同上参数注入
SQL注入-高危 /system/user/list?orderBy=xxx 用户列表排序 orderBy参数未过滤，时间盲注
SQL注入-高危 /system/dict/data/list 字典列表 dictType参数未过滤，UNION注入
XXE-中危 部分XML接口（如/tool/gen/importTable） XML解析 默认未禁用外部实体，读取服务器文件
Fastjson反序列化-极高危 所有JSON接收端点 Fastjson RCE RuoYi集成Fastjson<1.2.83（<=v4.7.1等旧版本），未禁用autoType/autoTypeCheck时，可控JSON反序列化致RCE
Actuator-高危 /actuator/* 同Spring Boot RuoYi集成Spring Boot Actuator，同样面临/heapdump、/env泄露

路径前缀：前后端分离版本默认/prod-api（生产）或/dev-api（开发），完整路径如/prod-api/system/user/list。

默认账号：admin/admin123（后台主账号）、ry/admin123（若依演示账号）、admin/admin（Druid）、nacos/nacos（Nacos集成）

历史漏洞重点：

  • Shiro权限绕过链（RuoYi ≤ v4.3.0 集成 Shiro < 1.5.2）：CVE-2020-1957、CVE-2020-11989、CVE-2020-13933、CVE-2020-17510、CVE-2020-17523
  • Shiro反序列化RCE（Shiro ≤ 1.2.4 / RuoYi ≤ v3.2.0 等集成旧版本Shiro的项目）：CVE-2016-4437 rememberMe AES密钥硬编码反序列化；后续RuoYi已升级Shiro，但二次开发项目仍可能残留旧版Shiro
  • Thymeleaf SSTI RCE（RuoYi ≤ v4.7.1）：/monitor/cache/*（getNames/getKeys/getValue）缓存名未过滤Thymeleaf模板致RCE
  • 任意文件下载（RuoYi < 4.5.1）：CNVD-2021-01931，/common/download/resource
  • SQL注入（RuoYi <= v3.2.0）：/system/role/list、/system/role/export、/system/user/list 等动态SQL拼接注入
  • Fastjson反序列化：集成Fastjson<1.2.83版本未禁用autoType
  • Druid默认弱口令：未修改druid monitor账号致数据库监控泄漏
